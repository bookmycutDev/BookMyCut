# 💇‍♂️ BookMyCut

## 📌 Description
**BookMyCut** est une application de réservation de services de coiffure permettant aux utilisateurs de :
- réserver un rendez-vous rapidement
- choisir un service et un coiffeur
- consulter les disponibilités
- gérer leurs rendez-vous

Le projet suit une architecture modulaire avec gestion des utilisateurs, des services et des réservations.

---

## 🚀 Fonctionnalités principales
- 🔐 Authentification (Client / Admin)
- 📅 Réservation de rendez-vous
- ✂️ Gestion des services de coiffure
- 👨‍🔧 Gestion des coiffeurs
- 📊 Suivi et gestion des réservations

---
